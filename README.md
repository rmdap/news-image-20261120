Entry for the make.fun bounty **"Sum up 20 November's world news in one image"**
(https://make.fun/bounty/news-image-20261120).

A front-page-style image summarising the day's world news: Russian missiles
landing in Poland leads the page, followed by the global market rout, GTA VI's
record $3.79bn day-one sales, the funeral barge capsizing in Nigeria, Cyclone
Akvan's landfall in India, the UK–EU summit deals, the Palisades Fire
arsonist's conviction, Bayer's $7.25bn Roundup settlement, the magnitude 6.7
Peru earthquake, Iraqi forces retaking the Kataib Hezbollah stronghold, the
COP31 talks hitting the wire, and a pancreatic-cancer pill shrinking tumours
in 44% of patients. All events happened or were first reported on Friday,
20 November 2026.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, ~184 KB). Python 3.13, standard
library only — the program simply copies the bundled `entry.png`.
